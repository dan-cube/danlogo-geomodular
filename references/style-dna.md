# 风格基因

> 几个音，一条规则，一段可以无限变奏的旋律。

## 目录
- 核心构成
- 基因
- 风格坐标：像谁，不像谁
- 旋钮：可以变的部分
- 模糊词在本风格里的意思

这一章描述**气质**，不描述具体的形状、颜色或工艺。每条基因都写明：是什么、为什么、试金石、常见误区。

**核心构成：构件与组合。** 一套同源、同度的几何构件是基础，有规则的组合是主角：构件越朴素，组合越重要；拆开时每一件都数得清，合起来时只看到一个完整的图形。构件是**整件的基本形**，标志通常只用 2–4 件，意思直接来自品牌名——名字里的一个字母、一个意思，变成这几件之间的一个关系。

只顾构件，会走到「一堆散件」：每件都好看，合起来不成形；只顾组合，会走到「融成一团」：构件的边界消失，看不出是由什么组成的。好的方案同时站在两边：**构件清楚，整体完整。**

## 基因

### 1. 同源
**是什么**：所有构件从同一个母形切分、拉伸或复制而来；用两种母形时，它们服从同一个尺寸单位，并且在组合里分工明确。
**为什么**：同源让构件彼此相认，怎么排都是一家人；这是「模块」和「拼贴」的分界。
**试金石**：把构件表单独摆出来，能说出它们共同的母形吗？
**常见误区**：为了表达意思临时加进一件来自别处的形——一件就足以破坏整体。

### 2. 同度
**是什么**：一个尺寸单位管住构件的粗细、大小与间距：每个尺寸都是这个单位的整数倍或简单比例，只有少数几档——标志有三件以上时分**大、中、小三档**，只有两件时两档的对比要拉开（约 2 : 1 以上），一眼分得出主次；同一种构件在每一处都一样大，不随位置渐渐变大变小。
**为什么**：同度带来秩序，系统才能铺开而不乱；三档大小带来层次，几件构件才有主角、配角和落点，而不是一排一样大的块。
**试金石**：指着任何一个尺寸，能说出它是尺寸单位的几倍吗？哪一件最大、哪一件最小，一眼看得出吗？
**常见误区**：为了凑形状，把某一件放大缩小到和别的都不成比例；让构件沿着螺旋、透视或弧线越来越小——渐缩一出现，模块就变成了插图；所有构件一样大，没有主次。

### 3. 定向
**是什么**：构件放在同一个网格上，只按固定的角度系统转动或镜像（例如只用直角，或只用一个固定的斜角系统）；每件构件的位置都能落回网格。
**为什么**：固定的网格和角度让组合有规则可循，也让体系里的每一次转向都显得有意。
**试金石**：把网格叠上去，每件构件都落在格子上吗？所有构件的方向，能用同一个角度系统解释吗？
**常见误区**：随手转一个「看起来合适」的角度；沿着曲线自由排布，没有网格。

### 4. 可数
**是什么**：构件之间有一致的间隙或明确的咬合，每一件都完整、边界清楚，可以数出来。
**为什么**：可数是「模块感」的来源，也是体系可以拆开重排的前提。
**试金石**：缩到 32 px，还数得出有几件吗？
**常见误区**：间隙忽宽忽窄；或者为了「整体感」把构件熔成一个轮廓，模块感消失。

### 5. 组合生义
**是什么**：意思主要来自排法——并置、围合、咬合、错位、转向、缺位——而不是来自某一件构件的形状。
**为什么**：这样构件可以朴素、通用，品牌的个性落在「怎么排」上；同一套构件才能排出整个体系。
**试金石**：说说这个图形的意思是怎么来的：是「这几件这样排」，还是「这一件长得像什么」？
**常见误区**：把一件构件画成具体的东西，组合退居其次。

### 6. 整件的面
**是什么**：构件是实的面，而且是**整件的基本形**——整圆、半圆、四分之一圆、两端圆的条、整半圈或整四分之一圈的等宽弧带、方与矩形、固定角的三角，从中选一族为主，可以按固定的角度系统整件转动（例如 45°）；形靠面和外轮廓成立，不靠描边。不为凑外形去切改一件，不用自由曲线，也不用折线去近似一段弧。
**为什么**：整件的基本形人人认得，几件就能把关系说清；切改过的形只剩一个外轮廓，组合的意思就丢了。面让每件构件有分量，小尺寸也清楚。
**试金石**：指着每一件，说得出它是哪一种基本形吗？画它的代码是不是只要一两行？
**常见误区**：用多边形裁出一个外形；为了像某样东西把一件削掉一角；用细线勾出构件的轮廓，结果读成一张图解。

### 7. 稀疏的偏差
**是什么**：在整齐的组合里，只有一处（标志）或极少几处（体系）有意不同：换色、换向、换大小或缺一件。
**为什么**：规则越整齐，一处偏差越醒目；视线和意义都落在那里。
**试金石**：偏差在哪里？它说出了什么？去掉它，标志是否变得普通？
**常见误区**：偏差太多，变成热闹的花纹；或者偏差只是为了好看，说不出意思。

### 8. 一个完整的构成
**是什么**：标志是从构件库里选出的一个组合（通常 2–4 件），外轮廓收拢成一个完整、有性格的抽象构成。它可以同时读出品牌名的首字母——条件是**元素先于字**：
- **元素先于字（可以）**：几件完整的基本形按本风格的规则排好，恰好读出一个字母；拿掉字母的联想，它仍是一个成立的几何构成。
- **字形先于元素（不可以）**：先写出一个字母，再几何化、加粗、换字体；拿掉字母的联想，只剩一个怪形。
- **象形（不可以）**：用构件去画一样具体的东西——动物、植物、器物、建筑、风景、人。那是图标库里的象形图，不是构成。
**为什么**：一串散件只是图案或编码；画一样东西，力量就落在「像不像」上，几何只是在模仿。抽象构成的意思来自构件之间的关系，读得出首字母时，品牌名就直接写在形里，不用讲故事。
**试金石**：遮住名字，第一眼读成「几件基本形组成的一个构成」吗（可以同时读出一个字母）？如果第一眼读成「一个换了字体的字母」或「一只鸟、一座山、一只眼睛」，不过。
**常见误区**：把一小段阵列直接当标志；为了读出字母去切改构件；画出一样东西再把它几何化。

## 风格坐标：像谁，不像谁

| 像（气质上） | 不像 |
|---|---|
| 包豪斯基础课与具体艺术的系统感 | 拼贴：来源不同、没有共同尺寸的形拼在一起 |
| 日本战后现代的几何平面，但颜色更克制 | 生成艺术：元素多、靠程序随机变化，没有人来挑 |
| 模数现代主义：一个单位，到处适用 | 孟菲斯的热闹与杂乱 |
| 一段由几个音反复变奏的旋律 | 扁平图标库：每个形单独成立，彼此没有关系 |
| 一本条理清楚、让人愿意读的说明书 | 只为显得高级而做的冷色块 |
| 案例的形：本风格只借方法 | 象形图标：用几何块画出的动物、器物、风景 |

## 旋钮：可以变的部分

风格靠上面的基因守住；下面这些旋钮每个项目都应该重新拧。**新项目的最终方案至少要有两个旋钮的取值与 `cases/index.md` 里所有案例明显不同**，除非用户明确要求。

| 旋钮 | 范围 | EonPoint 方案 A 的取值（只作对照） |
|---|---|---|
| 母形 | 圆弧系 ↔ 直角系 ↔ 斜角系 ↔ 两种母形配合 | 圆弧系 |
| 构件种类 | 2 种 ↔ 6 种 | 3 种 |
| 接合 | 留缝 ↔ 相切 ↔ 咬合 | 留缝 |
| 角度系统 | 直角 ↔ 固定斜角 ↔ 等分圆周 | 直角 |
| 排列规则 | 序列重复、逐行错位、镜像、旋转阵列、密度渐变…… | 序列重复，逐行错位、转向 |
| 力度 | 轻巧 ↔ 厚重 | 中偏厚 |
| 温度 | 严谨 ↔ 亲和、带玩味 | 亲和 |
| 色彩 | 单色 ↔ 一处偏差色 ↔ 按构件种类分色 | 单色加一处偏差色 |
| 字的性格 | 用构件拼出的字 ↔ 与构件同端点的几何字 | 与构件同端点的几何字 |
| 构图 | 紧凑收拢 ↔ 舒展开放 | 紧凑收拢 |

## 模糊词在本风格里的意思

| 用户说 | 在几何模块里是 |
|---|---|
| 高级、有质感 | 构件更少、尺寸关系更严；偏差更稀疏；颜色更克制 |
| 有张力 | 构件的大小对比拉开；或用咬合、错位制造一处紧张的接合 |
| 年轻、活泼 | 构件种类与转向更多一点；偏差可以更醒目；温度旋钮拧向亲和 |
| 温暖、亲切 | 母形偏向圆弧；接合偏向相切；颜色来自温暖的材料 |
| 科技感 | 角度系统更严格，网格更细；构件更薄；偏差像信号一样明确 |
| 简洁 | 减少构件种类，而不是减少规则 |
| 有设计感 | 排法更聪明（一形两读、围合出负形），而不是构件更花哨 |
| 稳重、可信 | 构件更厚，组合更对称，偏差更少 |
| 不够整体 | 统一尺寸单位与接合方式；检查是否有来自别处的构件 |

## 整体试金石

交付前，用这几个问题整体看一遍。第 3 阶段只有图形（多半是黑白），判断第 1、2、3、4、5、8、9 问；其余到第 5 阶段有了字和色再判断。

1. **首先是构成**：遮住名字，它第一眼是几件基本形组成的一个完整构成吗？读得出首字母时，是元素先于字吗？不是象形图、不是换了字体的字母、不是图标吗？
2. **一家人**：构件表里的每一件都出自同一个母形、同一个尺寸单位吗？
3. **数得清，合得拢**：拆开能数出几件，合起来外轮廓完整吗？
4. **秩序从哪里来**（本风格的正向判断）：能指出这个图形的母形、尺寸单位和排列规则吗？
5. **意思在排法里**：这个图形的意思，主要来自构件怎么排吗？
6. **能长成系统**：用同一套构件排出三种别的组合，还是同一个品牌吗？
7. **偏差有意义**：偏差只有一处，而且说得出它的意思吗？
8. **记得住**：剪影、反白、十字描述都不像一个常见图标——它只属于这个品牌，而且力量来自组合，不是靠加粗加满换来的。
9. **对照尺**：把它和 `cases/` 里的案例标志（黑白）渲染在同一张图上：件数不多于案例，每件同样完整，大中小同样分明，站得同样稳？形不能像案例，但这几样不能输给它。第 2 阶段起就用。
