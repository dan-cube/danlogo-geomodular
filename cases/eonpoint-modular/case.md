# 案例：EonPoint 亿触点 · 方案 A「模数」

> **只借方法，不借形式。** 这里的母题、母形、构件、颜色和字形都是 EonPoint 的答案，不是几何模块风格的规定。本案的标志可以读成字母 P 加句号——那是这个品牌名的答案；本 skill 要求新项目的标志首先是一个图形。

## 1 简报

- 品牌：EonPoint 亿触点，面向企业的 AI 科技公司（自研 Agent，提供 AI 软件、云与 SaaS、正版软件授权）
- 用户要求：高审美、国际化的 AI 科技感；没有美学缺陷（例如不要密集的点）；不要幼稚明亮的颜色，不要老土的商务风

## 2 过程

| 轮次 | 做了什么 | 用户原话 | 教训 |
|---|---|---|---|
| 概念 | 三个主题方向 × 三个方案 | 选出两个大方向，但「似乎有些粗糙不够精细，而且似乎有点拼接感而丧失了整体感」 | 几件形各自成立、却没有共同规则，就是拼接感 |
| 精修 | 每个方向三条以上的精修路线，与原版对比 | 选定方向，继续深化 | — |
| 深化 | 回到原版，连同中英文字标一起做三套方案 | 保留其中两套做完整提案 | 字和图要出自同一套构造 |
| 配色 1 | 主色用亮蓝 | 「色系似乎有点点幼稚明亮」；「蓝色主色太幼稚了」 | 屏幕默认的亮色没有材料温度 |
| 配色 2 | 换一套「硅谷式」的高级配色 | 「蓝色还是太幼稚普通了」，要求做三个色系方向（国际科技、时尚艺术、原研哉常用色） | 一次给出明显不同的三个色系方向 |
| 配色 3 | 三个方向并排 | 「方案A用 生成 · 墨 · 弁柄这套色系吧」 | 最终落在材料本色 |
| 逆向 | 把这套方案逆向成风格 | 「方案A不应该锁死圆形，而是应该用几何模块化的拼搭」，并指向辅助图形的感觉 | 风格是构件的规律，不是圆 |

## 3 最终方案

- **标志**：三件实心构件——两端圆的竖条、半圆面、圆——留着相等的缝组合在一起
- **构件表**：母形是圆；构件有整圆、半圆、两端圆的条三种；条的粗细等于圆的直径
- **规则**：尺寸单位 22（标志高度 100）；半圆半径是它的一倍半；所有缝隙等宽；圆形各做少量光学补偿
- **偏差**：只有圆用强调色
- **字标**：中英文都用与条同样的圆头、正圆弧构造；中文两端对齐到英文的宽度
- **色彩**：生成 #EEE7D7、墨 #232220、弁柄 #9A3B1E（偏差），砂与银鼠做辅助；比例约 65 / 25 / 8 / 2
- **辅助图形**：三种构件逐行按同一序列排列，每行转四分之一圈；约五件里有一件换成强调色

图片见 `images/`：`mark-main.svg`（标志）、`lock-*.svg`（组合）、`word-*.svg`（字标）、`pat-*.svg`（辅助图形）、`cw-*.svg`（五种配色）、`cons.svg`（构造图）、`clear.svg`（安全空间）、`dont-*.svg`（错误用法）。

## 4 反向拆解对照表

| 风格要求 | 在本案中的体现 |
|---|---|
| 同源 | 所有构件出自同一个圆 |
| 同度 | 条的粗细 = 圆的直径；缝隙统一 |
| 定向 | 只用直角转向 |
| 可数 | 三件构件互不接触，数得清 |
| 组合生义 | 三件并置，读成品牌名的意思 |
| 以面成形 | 全部是实的面，没有描边 |
| 稀疏的偏差 | 只有一件换色 |
| 一个完整的图形 | 三件合起来是一个紧凑的外形 |

## 5 旋钮取值

| 旋钮 | 取值 |
|---|---|
| 母形 | 圆弧系 |
| 构件种类 | 3 |
| 接合 | 留缝 |
| 角度系统 | 直角 |
| 排列规则 | 序列重复，逐行错位、转向 |
| 力度 | 中偏厚 |
| 温度 | 亲和 |
| 色彩 | 单色加一处偏差色 |
| 字的性格 | 与构件同端点的几何字 |
| 构图 | 紧凑收拢 |

## 6 可以借的方法

- 先画构件表，再画标志
- 一个尺寸单位驱动所有尺寸（见 `examples/eonpoint-modular/src/`）
- 用同一套构件排出辅助图形，体系不另起炉灶
- 配色一次给出三个明显不同的方向，放在完整组合上比较
